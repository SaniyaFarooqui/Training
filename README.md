# Backend REST API

A backend REST API built using Node.js, TypeScript, Prisma and PostgreSQL.

## 🚀 Features

- User authentication and authorization
- Login and logout functionality
- Role-based access and permissions
- Product management
- RESTful API development
- PostgreSQL database integration
- Prisma ORM
- PDF generation
- API testing with Postman

## 🛠️ Technologies Used

- Node.js
- TypeScript
- Express.js
- Prisma
- PostgreSQL
- REST API
- Postman
- JWT Authentication

## 📁 Project Structure

- `src/` - Application source code
- `prisma/` - Database schema and Prisma configuration
- `types/` - TypeScript types
- `package.json` - Project dependencies and scripts

 ## 🔐 Authentication

The project includes authentication and authorization using secure middleware and JWT-based authentication.

## 📌 Purpose

This project was developed as part of my backend development training to practice building and testing REST APIs, database integration, authentication and authorization.
